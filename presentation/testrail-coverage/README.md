# Презентация «Покрытие кейсов TestRail автотестами»

Исходники слайдов к изменению `openspec/changes/testrail-autotest-coverage`.

- Опубликованная версия (Slides): https://claude.ai/artifact/NhQ2BiQ4omH18ctKWp6y97 — доступ выдаётся через Share.
- `deck.json` — порядок слайдов, разделы, шрифты.
- `deck.css` — общие стили (холст 1920×1080).
- `slides/<id>.html` — по слайду на файл; заметки докладчика — в `<aside>`.

Перед показом заполнить: `[Имя докладчика]`, `[дата]` (cover), `[название эпика]`, `[N недель]` (ask).
