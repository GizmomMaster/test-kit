Три источника

Матрица из репозитория, результаты тестов, названия кейсов из TestRail (только чтение)

Для людей и для агента

HTML — ссылка из MR для QA; JSON — агенту qa на приёмке

Предупреждает

Понижения покрытия, тест не найден, метка и матрица расходятся

Чтобы QA не разбирался в YAML-матрице, pipeline собирает человекочитаемый HTML-отчёт. Он сгруппирован по кейсам — так QA думает — и для каждого кейса сразу говорит, что сделать руками. Отчёт соединяет матрицу из репозитория, результаты тестов и названия кейсов из TestRail; в TestRail он ничего не пишет. Рядом лежит JSON — его QA передаёт агенту qa на приёмке, чтобы агенту не нужен был доступ к GitLab. Саму джобу в CI встраивают SRE по нашей постановке.
