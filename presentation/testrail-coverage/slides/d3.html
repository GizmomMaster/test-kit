Стадия 3. Когда pipeline MR прошёл, CI-джоба, которую встроят SRE, собирает отчёт покрытия: берёт матрицу из репозитория, результаты тестов и названия кейсов из TestRail. В TestRail она ничего не пишет. QA открывает HTML по ссылке из MR и сразу видит ручной остаток, а JSON передаёт агенту qa — у агента нет доступа к GitLab. Агент считает объём ручной проверки по фактическому статусу; если хоть один тест кейса красный — облегчения нет. После прогона, с согласия QA, результаты пишутся в TestRail, а в два новых поля — фактическое покрытие и список тестов. Перенос кейсов из Change Request в основную базу после релиза делает QA, как и сейчас.
